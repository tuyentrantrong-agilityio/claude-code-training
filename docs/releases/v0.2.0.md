# Release v0.2.0

Date: 2026-11-02. Range: `v0.1.0..origin/practice`, 19 merged changes.

## Highlights

The repo moved from a set of daily exercises to a full feature workflow. A kickoff
harness (lead, BA, QA and Dev agents, three human gates, scores from scripts) turned a
vague request into three tickets, which were built test-first with evidence taken in
the browser by the tools, reviewed by a read-only reviewer agent and fixed. The work
moved to GitHub with CI on every pull request, and each lesson from the rework became a
hook, a CI check or a rule (`docs/retro.md`). The whole flow is in `docs/playbook.md`;
the evidence is under `intent/2026-11-02-minimum-raise/evidence/`.

# Recapz API contract (T32)

Status: **Proposal** for the MVP. The OpenAPI spec is generated by FastAPI from these
routes and committed as `openapi.json` once the backend skeleton exists (T08); this doc
is the reviewed source until then.

## 1. Conventions

- Base path `/api/v1`, JSON bodies, `snake_case` fields, timestamps in ISO 8601 UTC,
  times inside a recording in milliseconds (`*_ms`).
- Auth: session cookie (HTTP-only). State-changing requests send the CSRF token header
  `X-CSRF-Token`.
- The organization comes from the session; it is never a path or body parameter.
- Pagination: `?limit=` (default 20, max 100) and `?cursor=`; responses return
  `{"items": [...], "next_cursor": "..." | null}`.
- Errors:

```json
{
  "error": {
    "code": "meeting_not_found",
    "message": "Meeting not found.",
    "details": {}
  }
}
```

| HTTP | Typical codes |
|---|---|
| 400 | `validation_error`, `unsupported_file_type` |
| 401 | `not_signed_in` |
| 403 | `not_invited`, `owner_only`, `csrf_failed` |
| 404 | `<resource>_not_found` (also for resources of another organization) |
| 409 | `stage_already_running`, `invite_exists` |
| 413 | `file_too_large` |
| 429 | `usage_limit_reached` |
| 500 | `internal_error` (with a request id) |

## 2. Auth and session

| Method | Path | Purpose |
|---|---|---|
| GET | `/auth/google/start` | Redirect to Google consent (sign-in scopes only) |
| GET | `/auth/google/callback` | Create session if the email is a member or has a valid invite; otherwise redirect to sign-in with `not_invited` |
| POST | `/auth/sign-out` | End the session |
| GET | `/me` | `{user, organization, role, csrf_token}` |

## 3. Meetings

| Method | Path | Purpose |
|---|---|---|
| GET | `/meetings?status=&q=&folder_id=` | List with counts per status in `meta` |
| POST | `/meetings/uploads` | Multipart: `file`, `language`, optional `title`. Returns the meeting (status processing) |
| GET | `/meetings/{id}` | Header data: title, status, stage, error, duration, participants |
| PATCH | `/meetings/{id}` | Rename, edit `summary`, set `folder_id` (later) |
| DELETE | `/meetings/{id}` | Delete with recording and index |
| POST | `/meetings/{id}/retry` | Retry the failed stage |
| GET | `/meetings/{id}/events` | SSE: `stage` and `status` events while processing |
| GET | `/meetings/{id}/recap` | Summary, follow-ups, key points, chapters, highlights, questions |
| GET | `/meetings/{id}/transcript?q=` | Segments with speaker, optional search |
| GET | `/meetings/{id}/people` | Talk share per participant |
| PATCH | `/meetings/{id}/participants/{pid}` | Rename a speaker |
| GET | `/meetings/{id}/audio` | Audio stream, supports `Range` |
| GET | `/meetings/{id}/export/transcript.txt` | Download |
| GET | `/meetings/{id}/export/recap.md` | Download |

Meeting summary object (list item):

```json
{
  "id": "uuid",
  "title": "Weekly product sync",
  "status": "ready",
  "stage": null,
  "error": null,
  "source": "upload",
  "platform": "file",
  "language": "en",
  "started_at": "2026-11-19T03:00:00Z",
  "duration_ms": 1860000,
  "summary_preview": "The team reviewed ...",
  "participants": [{"id": "uuid", "display_name": "Maya Chen"}],
  "folder": null
}
```

## 4. Follow-ups

| Method | Path | Purpose |
|---|---|---|
| GET | `/follow-ups?owner=me|all&state=open|done` | Items with meeting title and `at_ms` |
| PATCH | `/follow-ups/{id}` | `{"state": "done" | "open"}` |
| GET | `/follow-ups/count` | Badge count for the sidebar |

## 5. Ask

| Method | Path | Purpose |
|---|---|---|
| GET | `/conversations` | Chat list (title, updated_at) |
| POST | `/conversations` | `{"scope_meeting_id": null | "uuid"}` |
| GET | `/conversations/{id}` | Messages with citations |
| POST | `/conversations/{id}/messages` | `{"text": "..."}`; response is an SSE stream |
| DELETE | `/conversations/{id}` | Delete a chat |

SSE events for an answer:

```
event: token
data: {"text": "The team agreed "}

event: citations
data: {"items": [{"meeting_id": "uuid", "meeting_title": "Weekly product sync", "at_ms": 1210000}]}

event: done
data: {"message_id": "uuid"}

event: error
data: {"code": "provider_unavailable", "message": "..."}
```

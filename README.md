# Recapz practice

Practice project after the Claude Code training: rebuild Recapz, a meeting notetaker
in the style of Read AI, from the Recapz design prototype.

- Prototype (UI and behaviour reference): https://claude.ai/artifact/5dS2kuzsPwZsnydb4Aj2Ji
- Feature inventory: `docs/recapz/01-feature-inventory.md`
- Backlog (approved task list): `docs/recapz/backlog.md`

## Status

Phase 0 (planning). No application code yet: requirements, architecture, data model and
API contract come first, then the Build Plan and Build Guide.

## Branches

- `recapz-practice`: base branch for this practice. Work happens on `feat/`, `fix/`
  or `docs/` branches created from it, merged back by pull request.
- `practice`: the Claude Code course work, unchanged.

## Course archive

The course examples (auction app, day folders, kickoff harness, hooks and skills) are
kept for reference under `archive/claude-code-course/`. They are not part of Recapz and
are not run by this branch.

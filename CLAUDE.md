# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project status

Training exercises, one folder per day (e.g. `day-02/`). Python stdlib only, no dependencies.

- Run the demo: `cd day-02 && python -m auction.demo`
- Run tests: `cd day-02 && python -m unittest discover -s tests -t . -v`

## Conventions

### Commit messages

- Always use the format `<type>: <short description>`, all lowercase, imperative mood, no trailing period.
  - Example: `feat: add rag compulsory security notebook`
  - Types: `feat`, `fix`, `docs`, `test`, `refactor`, `chore`
- No `Co-Authored-By` trailer, no "Generated with ..." line, and no other line that mentions AI or Claude.
- Merge request descriptions follow the same rule: no AI attribution lines.

### Code

- Everything in code is written in English: identifiers, comments, docstrings, log and error messages, test names.
- Use plain ASCII only. No emoji or icons, and no typical AI-generated characters such as em dashes, curly quotes, arrows, check marks, or bullet symbols.
- No comments or lines that show the code was AI-generated (e.g. "Generated by", "As an AI", "Here is the updated code").
- Keep comments short and only where the code is not self-explanatory.
